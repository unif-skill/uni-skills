# CI 自包含行为题库

本目录为 Uni Skills 的只读 CI 评测输入，覆盖本包 7 个技能的发现正例、发现反例和内容应用。它补充既有[任务题](../cases.md)与人工判据，不替代原有题库、历史记录或真实工程验证。

## 覆盖与执行边界

| 模式 | 题数 | 作答模型可见资料 |
| --- | ---: | --- |
| application | 7 | 一个完整的目标技能目录、题面与题内 fixtures |
| discovery_positive | 7 | 本包技能的 name/description、题面与题内事实 |
| discovery_negative | 7 | 本包技能的 name/description、题面与题内事实 |

合计 21 题。每个技能均覆盖三种模式，ID 采用 `<skill>-<mode>`。应用题仅提供该技能自身目录，包含其引用的配套文件；不要求安装兄弟技能，也不读取其他私有仓库、本机路径、业务凭据或网络资料。题内 `AGENTS.md`、接口、diff、事件与执行记录都是已标明的匿名合成材料，不是实际执行证据。片段不构成完整可构建项目。

发现题仅评价本包目录。`required_skills` 必须选中，`forbidden_skills` 不得选中；未列入约束的技能不按总加载数机械计错。原始素材中的跨包要求已经移除，因此本包反例通过不能证明另一个技能包被正确发现。题面保留自然请求，不加入提示应选其他包的答案。

应用题由独立上下文依据冻结 `rubric` 逐项审阅完整回答与读取轨迹，判据不交给作答模型。判据检查具体状态归属、实际消费者、异常/取消时序、授权及证据范围；只出现关键词或正确复述标题不能算通过。模型评阅需保留理由并人工抽查。

## 文件格式

`cases.json` 根为 `formatVersion: 1` 和 `cases` 数组。每题包含：

| 字段 | 用途 |
| --- | --- |
| id、skill、mode | 稳定题号、所属技能、模式 |
| prompt | 自然请求及只读范围 |
| fixtures | 相对路径到 UTF-8 文本的映射；运行时置于 `fixtures/` 下 |
| rubric | 不向作答模型公开的语义判据 |
| required_skills、forbidden_skills | 发现模式的本包集合约束 |
| source | 原有题文件/编号、固定来源与适配范围 |

应用技能由运行器置于 `skills/<skill>/`。资料路径必须相对、唯一且不能穿越目录；题目可以在源代码/文字中展示合成路径，但不会取得对应真实资源。

## 来源与维护

依据本仓对应原题适配为 21 项 CI 匿名 fixtures，保留题意、契约与语义判据，发现集合限定本包。每题 `source` 指向原有题文件及对应技能场景，并说明适配范围。既有命名、生成类型、实例状态、跨轮结果、资源交接、独立产物消费、交付授权和文档证据边界仍由原题语义约束。

变更题目时同时核对题面、fixtures、判据和来源。比较候选与基线时使用同一份题库、模型与判据；题库、素材或模型变化后不能把结果直接拼成趋势。新增技能应补齐正例、反例和应用题，不以更多易题替代原有边界。

CI 这里只观察固定资料下的发现与书面应用。真实宿主自动加载、源码实施、完整测试、归档构建、独立消费者、设备及真实业务仍需各自评测。未执行、缺配置或资料不足应保留为证据不足，不能记成行为通过。
