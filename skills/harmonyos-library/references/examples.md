# 原生运行示例

开发联调可以使用源模块，交付前另外使用打包产物验证公开消费。示例不借助库私有深路径、作者工作区别名或未交付文件补齐公开接口；仅有源码路径示例和一次本地构建不足以证明可分发。

按变更展示真实输入、事件、错误、取消和资源交接；权限、设备能力、初始化顺序与宿主生命周期从实际依赖核对。可控替身用于展示或测试时明确标识，不把模拟回执写成真实厂商成功。命令和设备条件从该工程取得。

原生示例与文档站分别验证。网站沿用已有工具，提供对应版本的原生运行入口或已核实的预览记录；静态站点不要求 HAR 引入 React、RN Web 或 Expo。网页近似预览及 iOS／Android 示例不替代鸿蒙运行。
