# HarmonyOS 库工程

以 HAR 的公开能力、实际消费者与工程采用标准为依据。源码开发、源模块接入、可分发产物和真实发布分别验证。

## 按任务读取

| 当前工作 | 资料 |
|---|---|
| 新库、应用抽库、公共入口、依赖、共享源码或打包发布 | [库生命周期](references/lifecycle.md) |
| ArkUI 示例宿主、公开消费和文档预览 | [运行示例](references/examples.md) |

本目录包含完整库工程指引，可独立使用。源码实现、文档与 GitHub 交付按工程有效约定执行，其他已安装技能仅作可选任务组合，不是前置依赖。

## 工程依据

先读目标库的维护入口、包清单、构建配置、导出、脚本与相关 CI，核对实际 SDK、Hvigor、OHPM 和采用记录。已有标准与发布流程继续有效；模板只提供起点，不证明公开能力、包内容或宿主已完成。

项目未指定模板时按真实依赖选择工程方式，不预设企业包名、最低 API、第三方提供方、注册表、CI 服务或网站框架。新建原生库不能直接套用 npm／React Native 模板；源码局部维护不重新初始化工程。

公开输入、默认行为、错误、取消和资源所有权来自有效契约。修改后同步实际导出、文档、示例与消费者，分别报告本次源码、产物、宿主和发布证据。发布目标、版本及外部操作按授权核对；本地构建不构成发布授权。
