# 平台接入与资源

## SDK 与 Context

先核对已采用能力、真实缺口和目标 SDK；API、Kit 导入、权限、错误码及可用范围从工程使用的 SDK 类型和官方资料确认。已有提供方与宿主配置继续有效，平台示例不改变工程采用的厂商、服务或业务语义。

Context 按调用 API 所需类型与真实拥有者取得。UIContext、UIAbilityContext 与其他 Context 不因名称相似而互换，也不以强制断言掩盖类型或生命周期问题。需要窗口或 UI 的操作使用仍有效的宿主；不将页面、Ability、窗口或其句柄藏进进程全局工具长期复用。

Stage 模型中 UIAbility 生命周期、WindowStage 事件与组件生命周期分别核对。平台依据见[华为 Stage 模型说明](https://developer.huawei.com/consumer/cn/arkui/arkui-stage)；具体回调和签名仍以项目采用版本为准。

## 原生操作与资源交接

权限申请、设备准备、能力调用、业务结果和资源收尾分别确认责任。权限被拒绝、能力不支持、厂商未返回最终回执或结果未知时保留真实状态，不用替代渠道或伪成功掩盖。

每项资源明确创建者、当前所有者、借用者和释放条件。临时文件、外部借用 URI、仍被 SDK 读取的媒体与已转交调用方的结果采用各自契约：

- 借用资源不因借用方取消操作而删除；交付之后由已约定的接收方承担责任。
- Promise 已结算或 UI 已关闭，不证明底层操作停止、句柄释放或文件已可回收。等待 SDK 约定的停止／释放信号，或按有效协议完成所有权交接。
- 收尾只作用于本轮拥有且已可释放的资源；重复关闭与迟到回调不得影响后续操作。未确认可释放时保持真实待处理状态，不擅自删除。
- 保留权限、并发、取消和错误保护；释放失败应能定位到安全的原因与操作关联，不将凭据、用户内容或文件信息无差别写入日志。

HTTP、流式事件、上传和 Web 容器转换保留原业务字段、取消及成功语义。涉及已有容器时核对当前来源、文档、授权和重复处理等安全边界；平台迁移不自动改变页面业务或扩大访问范围。

## 验证边界

从目标工程取得真实的构建、静态检查与测试命令，不假定每个工程都有相同 Hvigor 任务或 Hypium 接线。替身测试用于可控的状态与失败路径；权限、硬件、厂商 SDK 和宿主生命周期按变更影响在对应环境验证。

源码／类型检查、纯逻辑测试、构建、模拟器／真机运行和真实业务验收分别说明。Node 或其他平台运行通过不证明原生鸿蒙可用；报告所用修订、SDK／设备条件、实际结果及未验证项。
