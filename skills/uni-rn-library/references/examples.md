# 运行示例

示例通过真实公开接口展示和验证库能力，按当前契约接回输入、受控值、事件及结果。固定数据可以作为输入，库组件和调用链使用实际实现，不增加产品未定义的业务操作。

## 原生接入

按所需平台保留或准备实际 example／消费宿主，配置真实依赖、权限、自动链接、初始化及必要补丁。需要使用方提供的凭证和环境明确说明，示例不嵌入私有配置。

没有自有原生模块不免除宿主要求。使用 Snack 或 Expo Go 前核对实际 SDK、版本及内置模块；不支持的能力用真实原生 example 验证，不以 Mock、截图或网页加载成功代替。

示例从包名和公开子路径导入；库内 example 可按现有工程解析公共源码。分发验收另按[打包与消费者](lifecycle.md#打包与消费者)验证实际产物。

## 文档交接

示例源码、公开类型和使用说明保持一致，文档站引用其入口或展示适用片段。网站的导航、页面、预览容器、生成及构建由文档站维护任务处理；原生依赖和示例运行仍由库工程维护，不为文档展示改变库实现。

## 验证

执行本次相关平台的构建和交互，核对状态、错误、取消、资源释放及真实消费者。相机、扫码、分享等硬件或厂商行为按相应设备和服务条件验证，模拟器不能替代未覆盖的能力。

分别记录公开类型、示例接线、原生构建、设备和服务结果。样例能运行不证明全部业务采用已验收。
