# 原生运行示例

示例由 API 26 的真实 ArkUI 应用宿主消费 HAR，新 UI 使用 V2，展示实际公开接口和必要环境配置。入口、版本与文档保持一致；尚未实现的导出标为目标或待实现，不把另一平台示例改包名当作可运行用法。

开发联调可以使用源模块；交付前按[打包与消费验证](lifecycle.md#打包与消费验证)在独立宿主验证实际产物，不借助私有源码或未交付文件补齐接口。

按变更展示真实输入、事件、错误、取消和资源交接；权限、设备能力、初始化顺序与宿主生命周期从实际依赖核对。可控替身用于展示或测试时明确标识，不把模拟回执写成真实厂商成功。命令和设备条件从该工程取得。

原生示例与文档站分别验证。网站沿用已有工具，提供对应版本的原生运行入口或已核实的预览记录；静态站点不要求 HAR 引入 React、RN Web 或 Expo。网页近似预览及 iOS／Android 示例不替代鸿蒙运行。

使用文档、API 说明、生成资料和示例按实际公开导出同步维护。已有文档生成链从同一代码源更新，不在示例中另写一份接口定义，也不为文档任务改写库能力。
