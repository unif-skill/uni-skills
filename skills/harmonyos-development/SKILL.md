# HarmonyOS 开发规范

按目标工程采用的 SDK、ArkTS／ArkUI 能力和有效契约实现功能。应用、库与平台宿主分别承担自己的状态和资源责任。

## 按任务读取

| 当前工作 | 资料 |
|---|---|
| ArkUI 输入、状态、组件和页面生命周期、主题与布局 | [组件与状态](references/components-state.md) |
| Context、原生能力、权限、异步操作、文件及验证 | [平台接入](references/platform-integration.md) |

本目录包含所需开发指引，可独立使用。目录与文件按工程有效约定组织；其他已安装技能仅按实际任务选用，不是安装或调用前置。

## 实施

先核对工程的 target／compatible SDK、实际编译器与工具版本、已有组件及公开能力。语言语法、装饰器、API 签名、权限和错误语义从所采用 SDK 的类型、官方资料与项目代码取得；资料快照或同名 API 不证明当前版本支持。

沿用项目已采用的状态管理与平台范围，不因新增组件自动升级 SDK、迁移 V1／V2 或增加低版本兼容。原生工程不照搬 TSX、Hooks、RN 样式、Metro 或 Pods；普通 TS 是否可用按真实依赖和目标互操作能力验证。

局部修改保留已确认的输入输出、视觉、交互、取消和业务成功条件。开发前确认实际消费者，完成后分别报告静态检查、自动化、构建、宿主运行及未验证的设备或业务行为；只读 API 查询不要求执行完整开发流程。
