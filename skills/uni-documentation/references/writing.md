# 表达与审校

## 增量维护

补充、修订或补齐已有文档时，先按语义查找相关正文、条目及其直接引用，确认哪些信息已准确覆盖、哪些需要纠正、哪些确实缺失。核对范围限于本次需求及必要关联，不把“补充”直接等同于新增段落。

已有内容准确时保留；同一职责的新条件并入原条目；旧说明失效时在原位置修正。只有新增内容承担独立职责、面向不同读者或无法合理归入现有结构时，才新增条目或章节。按信息含义与职责判断重复，不能仅凭标题相同就合并，也不能因措辞不同就保留两份同义说明。

## 选择呈现方式

先判断读者需要理解的信息关系，再决定用段落、列表、表格、步骤或示例。阅读效果以能否迅速找到要求并完成操作为准，不以字数最少或固定模板为目标。

| 信息关系 | 优先表达 | 组织要点 |
|---|---|---|
| 多项同类要求或对照 | 表格 | 如依赖与版本、平台差异、能力入口、参数、状态与结果；列出真正需要比较的维度 |
| 有先后顺序的操作 | 编号步骤配合命令 | 前提先说明，每步围绕一个动作，必要结果紧随其后 |
| 并列且无需逐列比较的信息 | 简短列表 | 如主要能力、注意事项、阅读入口，避免写成长段枚举 |
| 调用或配置方法 | 最小有效代码示例 | 包含必要上下文，详细分支链接到对应指南 |
| 原因、概念与设计取舍 | 短段落 | 先说明结论，再解释与当前任务相关的依据 |
| 文字难以说明的关系或流程 | 项目支持的图示 | 只有能减少理解成本时使用，正文和图示保持一致 |

表格先确认每行代表的对象和比较维度，再扩展原行或增加新的比较项。版本表明确“支持要求”和“已验证环境”的不同含义；补丁需要的精确版本另行注明。单元格保持简短，复杂配置和长说明放在对应指南。单个事实可以直接写成一句话，不为使用表格而增加空列或重复信息。

README 按初次接入的顺序呈现：简短用途与范围、必要准备、安装、最小用法、详情入口。只保留直接影响开始使用的信息；完整 API、平台配置、开发和验证流程归入对应资料。必要限制仍在相关操作附近可见，不能藏在长页末尾或仅剩链接。

同一要求在入口概括、在所属文档详细说明；不重复整段配置或整张表。调整后以读者任务通读，核对标题、表格、步骤与示例是否连贯，桌面和窄屏是否便于阅读。

## 表达

- 开头给出明确用途。段落先写读者最需要知道的结论，再展开必要条件和细节。
- 使用常见词和具体动词，说明谁执行、对什么操作、得到什么结果。一个术语对应一个含义。
- 保留准确的技术术语；第一次出现且读者可能不熟悉时简短解释。代码标识不为追求口语化改名。
- 条件写在操作前，结果紧随操作。普通说明使用短段落；顺序操作使用编号列表；并列项和字段比较使用列表或表格。
- 用标题和分组组织信息。删除重复铺垫、宣传式评价、聊天措辞和与当前读者任务无关的开发过程。
- 链接文字说明目标内容，例如“安装配置”“错误处理”，读者无需先点击才能判断用途。

例如，接口确实要求等到回调才能删除文件时，可以写成：

> 取消后，底层操作可能仍在读取文件。收到 `onSourceReleased` 回调后再删除源文件。

这句话保留取消和清理的关系；不能为了精简改成“取消后删除文件”。具体回调名称和行为仍需由本项目源码或契约证明。

## 准确性核对

| 内容 | 核对依据 |
|---|---|
| 功能、默认值、错误与副作用 | 已确认契约、公开实现及实际调用 |
| 签名、导入、类型和导出 | 当前公开入口、类型或生成源 |
| 安装、依赖与脚本命令 | manifest、锁文件、脚本及接入说明 |
| 支持平台与版本 | 项目支持声明，必要时核对目标 SDK 官方资料 |
| 已验证、已发布或已部署 | 对应版本、环境及真实执行记录 |
| 未决内容 | 明确的草案或问题，不能写成现成功能 |

源码说明当前实现，需求和有效契约说明应有行为。两者不一致时记录差异和影响，不能仅通过改文档把缺陷变成要求。历史运行记录只证明当时范围，不能当作本轮检查。

## 审校与验证

先通读文档完成读者任务，再结合修改前后的差异核对表达、事实和维护来源：新增内容应对应实际缺口；删改应保留有效的安装条件、权限、默认行为、失败、取消、并发、文件和其他资源责任。重要限制放在相关操作附近。

按实际修改检查 Markdown/MDX、相对链接、导航及锚点，使用已有生成与文档构建命令。示例涉及接口时，尽可能用实际公开类型检查；未运行的片段说明验证范围，不把仅阅读当成执行。

网站文案修改在真实页面检查标题、换行、导航和必要视口；布局未变时不要求重做站点。脚本说明核对实际参数与默认行为，文档编写本身不授权执行有副作用的命令。

只改变需要改进的内容。有效设计、计划、许可、署名和历史结论按自身职责保留；格式整理不能掩盖内容变化或改写事实。
