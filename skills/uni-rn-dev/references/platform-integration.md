# 平台接入与验证

## 依赖与宿主

依据已核实的 SDK 版本、公开能力与使用场景确定宿主接线。已有组件、Hook、操作与类型直接使用，自有适配承接真实语义差异、宿主参数或资源处理。

主题、字体、手势、安全区和弹层宿主按公开接口组装；原生依赖的自动链接、权限、初始化、Pods/Gradle 及补丁按项目配置。原生配置变化需对应重建，JS 热更新不能证明原生接线更新。

配置和凭证从明确来源传入，公共组件与库不读取应用私有账号、路由或整份业务 store。已有日志与失败处理继续有效，避免复制运行时或在页面重复接入同一设备流程。

## 平台差异

根据真实差异使用平台分支或平台文件，按 Metro 和项目配置核对解析。共享入口表达支持范围，不把成功 Mock 当正式平台实现。

RN Web、iOS 和 Android 分别验证所需环境。没有 Web 实现的原生库可提供文档或原生示例，不为浏览器演示擅自更换 SDK；Expo Go 是否可运行由实际内置模块和版本决定。

本技能不提供 ArkUI 实现规范。同名原生鸿蒙库、相似类型或无框架导入不能证明 RN 接口可迁移；跨端行为按共同契约对齐，语法和接线分别处理。

## 验证

使用项目当前的类型、lint、组件和逻辑测试，验证被修改的真实实现与事件。外部依赖可以替换，被测状态、映射与交互不换成自证成功的替身。

组件检查受控值、事件、默认值、错误及必要 UI 状态；宿主和异步流程检查多实例、切换、取消、卸载和迟到结果。宿主或组合变化还需检查实际消费者的事件分派、关键操作、键盘、滚动避让和关闭重开后的布局；直接调用回调或替换掉被改宿主不能证明这条接线正确。原生依赖变化另检查构建及设备行为，浏览器或模拟器不能替代未覆盖的硬件场景。

按实际变化选择验证对象：

| 变化 | 本地验证 | 按影响补充 |
|---|---|---|
| 工具或 Hook | 输入输出、边界或生命周期 | 返回语义变化的实际消费者 |
| 组件 | props、展示、事件、默认值及错误 | 实际组合；布局、键盘、手势及弹层的界面或设备表现 |
| 能力适配 | 真实适配逻辑及可替换的外部依赖 | 消费场景、协议与宿主接线 |
| 公共类型或常量 | 类型检查、生产方及消费者 | 码值、单位和默认值等运行语义 |
| 宿主、初始化或共享 UI 状态 | 真实读写者与入口 | 多实例、切换、卸载和实际平台行为 |
| 原生依赖 | 适配契约及相关上层调用 | 对应平台构建、设备及受影响的 Web 预览 |

测试文件与 fixture 按工程采用的组织方式定位。Jest 的相关测试选择可辅助缩小范围，路由、动态注册、协议和跨仓消费等非普通导入关系仍须核对；缺少关系时补齐相关组合，不以静态选择命令证明影响完整。同一模块并非全部重跑的唯一理由，合并与发布仍执行工程规定的完整门禁。

应用验证自身的库消费、组合及宿主接线，库工程验证内部行为；不在应用维护另一套库内部测试。文件迁移与状态逻辑变更分别选择受影响验证，不能仅以文件数或所在目录决定范围。

测试、构建和现场参数来自实际工程，核对源码修订、编译配置、候选产物与实际运行目标。保留有效检查与断言，按变更涉及的层级分别报告静态、自动化、构建、安装、启动、连通和业务证据及未验证项，不把类型或截图检查写成设备或真实业务验收。
