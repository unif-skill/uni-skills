# 组件与状态

## 组件与组合

复用已采用的设计系统、组件、Hook 和公开类型。组件通过 props、children、渲染入口和事件接收输入、返回用户操作；业务请求、确认责任和结果采用由实际场景维护。

受控值使用同一来源，组件可持有光标、展开和局部编辑等自身状态。拆出子组件不要求建立全局 store，也不将仅服务一个场景的组合提前提升为公共组件。

先核对组件的完整交互、状态归属和真实调用，名称与外观相近不代表满足需求。满足当前契约时直接组合或复用；职责一致且能合理补足时扩展，无法合理满足时在授权内替换或新增。业务、平台和实例差异分别保留。

## Hook 与生命周期

按当前 React 版本的 Hooks 规则维护调用顺序和依赖。普通 Hooks 从函数组件或自定义 Hook 的规定位置调用；组件渲染保持可重复，设备操作和订阅不在渲染过程中启动。

Effect 负责其创建的订阅、计时器或连接，在依赖变化和卸载时按实际契约清理。引用依赖与回调读取的数据一致，不通过省略依赖制造隐式旧值。仅为减少 render 不屏蔽有效业务更新。

异步操作捕获对应目标与实例，取消、卸载、身份或目标变化后，旧结果不能修改新实例。等待结束、底层停止与文件可释放可能是不同事件，按原契约分别处理。

## 样式与可访问性

先使用当前主题、字号、间距和材质配置；布局和状态表达清楚，再做必要结构调整。运行期尺寸和状态传入相应样式逻辑，避免复制主题值或另建同义状态。

中文长文本、动态字号、窄屏、键盘、滚动、手势和弹层按本次场景验证。保留有效的角色、标签、可点击范围与焦点行为；性能优化不能移除无障碍或取消保护。

共享状态按真实读写者订阅。局部输入不无故重建整个业务集合；跨组件协调只发布真正改变的语义，不为减少 render 缓存整棵 JSX 树。

依据：[React Hooks 规则](https://react.dev/reference/rules/rules-of-hooks)。具体依赖按项目采用版本读取。
